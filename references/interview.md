# The interview

Ask in the user's language, before any file is written. Round 1 has the questions that change the whole video;
round 2 only what is still open. With the question tool, one question per topic, 2 to 4 options (the recommended
one first), the user can always type their own answer. Skip a question when the user already answered it in the
request, and say what you took from the request.

## Round 1 (always)

1. **What are we launching, and where is it?** Product name, link (site, app store page, repository), one line on
   what it does. If there is no public link yet: a local folder (`file:` site) or the user's own screenshots.
2. **What must the video do?** Options: announce a launch / show how it works / get people to try it / get
   contributors or stars (open source). Decides the order of scenes and the end card.
3. **Where will it be posted?** Options: Instagram, TikTok, Shorts (9:16) / YouTube, X, LinkedIn, a talk (16:9) /
   both (default). Decides `formats`.
4. **How long?** Options: about 30 s / about 45 to 60 s (default) / about 75 to 90 s. Reels and Shorts keep people
   watching at 30 to 75 s; above 90 s only for 16:9.

## Round 2 (what is still open)

5. **Language** of the words on screen (default: the user's language).
6. **Light, dark or both?** Default: what the site uses; both if it has a dark mode.
7. **What to show** (multi-select): the home page / the search or main input being used / the mobile site in a
   phone / numbers (only real ones: ask which) / the main features as cards / "open source" with the repository /
   your own screenshots or pictures.
8. **Tone and music**: calm and clear (default, `calm`) / upbeat and energetic (`bright`) / minimal, almost silent
   (`minimal`) / no music (`none`, e.g. for a voice-over added later).
9. **Who signs it?** A maker logo at the start ("presents") and/or at the end, a credit line (data sources,
   licence, partners). Ask for the logo files.
10. **Colours and font**: the site's accent colour (default: read from the site), a Google Font if the brand uses
    one (default: the system font).
11. **Anything to avoid?** Pages, words, numbers, competitors, claims that need legal approval.

## Defaults when the user says "decide you"

Both formats, the site's own theme(s), 45 to 60 s, the user's language, `calm` at 105 BPM, a story of: problem
(text) > meet the product (page, brand) > it in use (page with typing, or a highlight) > on the phone > numbers or
cards > open source (if it is) > end card. Say which defaults you used.

## Posting notes (give them with the files)

- **Instagram Reels**: 9:16, up to 90 s for reach (longer is allowed); pick a cover frame with the product name;
  write the caption in the post, the video's bottom area stays free for it.
- **TikTok**: 9:16; the right edge has the buttons (the layout leaves it free); add the link in the bio.
- **YouTube Shorts**: 9:16, up to 3 minutes; the title is the hook.
- **YouTube / X / LinkedIn**: 16:9; X and LinkedIn autoplay muted, so the titles must tell the story alone (they
  do: every scene has words); put the link in the first line of the post.
